# Agent Skills Repository

A comprehensive collection of 201 production-ready agent skills for AI coding assistants including **Replit Agent**, **Warp Terminal**, **Antigravity**, **Claude Code**, **Cursor**, and more.

## ðŸš€ Quick Start

### 1. In Replit Agent
- In your Repl, open the Agent chat.
- Click the **+** (plus) button â†’ Select **"Use a skill"**.
- Choose **"Import from GitHub"**.
- Paste this repository URL:
  \\\
  https://github.com/roshankodi/agent-skills
  \\\
- Click **"Preview skills"** and select the skills you want to import.

Alternatively, in any Replit Shell / Terminal, install all skills with:
\\\ash
npx skills add roshankodi/agent-skills --all
\\\

### 2. In Warp Terminal
Clone or copy into your Warp skills directory:
\\\ash
git clone https://github.com/roshankodi/agent-skills ~/.agents
\\\
Or set your \WARP_SKILL_DIRS\ to include the \skills\ folder.

### 3. Using the \skills\ CLI
\\\ash
# Install all skills globally
npx skills add roshankodi/agent-skills -g --all

# Install a specific skill
npx skills add roshankodi/agent-skills --skill fastapi-templates
\\\
